# Employee Task Management System

## Project Overview
A full-stack web application developed to manage employee records and assign and track tasks.

## Technologies Used
- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- ORM: Spring Data JPA

## Features
- Dashboard to view employee and task information
- Add, edit, view and delete employee records
- Create and assign tasks to employees
- Update task status
- Store and retrieve records from MySQL

## Application Architecture
React → Spring Boot REST APIs → Spring Data JPA → MySQL

## How to Run

### Backend
1. Configure MySQL database credentials.
2. Run the Spring Boot application from STS.

### Frontend
1. Open the frontend folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
